## 1. 정보 구조

핵심 아이디어: **의상 사이즈를 장비 슬롯에 붙인다.** 사이즈는 따로 노는 표가 아니라 "이 슬롯에 맞는 장비 규격"이다.

| 섹션 | 항목 | 게임식 표현 | 기본 공개 범위 |
|---|---|---|---|
| 프로필 | 닉네임, 칭호, 만 나이 | 캐릭터명 / Title / Lv. | 공개 |
| 클래스 | 직업군 + 실제 직업명 | Class / Subclass | 클래스 공개, 직업명 비공개 |
| 신체 | 키, 몸무게, 골격근량, (체지방률) | Base Stats | 비공개 |
| 장비 | 투구 = 머리둘레/모자, 상의 = 상의 사이즈, 하의 = 허리둘레·하의 사이즈, 신발 = mm | Equipment Slots | 슬롯 외형 공개, 수치 비공개 |
| 자산 | 구간 | Wealth Tier | 비공개 |

### 클래스 매핑

| 클래스 | 직업군 | 컨셉 |
|---|---|---|
| 전사 | 현장·제조·운동·영업 | 몸으로 돌파 |
| 마법사 | 개발·연구·데이터 | 지식으로 세계를 조작 |
| 탱커 | 공공·관리·CS·운영 | 버티고 지킴 |
| 힐러 | 의료·돌봄·교육 | 남을 회복시킴 |
| 레인저 | 디자인·기획·마케팅 | 원거리 정밀 타격 |
| 상인 | 자영업·금융·사업 | 자원 순환 |
| 음유시인 | 크리에이터·예술 | 버프와 영향력 |

### 자산 티어

- 1억 미만: 천만 원 단위 10구간
- 1억 이상: 억 단위 구간
- **정확한 금액은 저장하지 않고 구간 인덱스만 저장한다.** 유출 시 피해를 최소화하기 위함.

| 레어리티 | 구간 |
|---|---|
| Common | 3천만 원 미만 |
| Uncommon | 3천만 ~ 1억 |
| Rare | 1억 ~ 5억 |
| Epic | 5억 ~ 10억 |
| Legendary | 10억 이상 |

## 2. 프라이버시 모델

### 필드 단위 공개 설정

Supabase RLS는 행 단위라 필드별 공개 설정을 직접 걸 수 없다.

- 모든 프로필 데이터는 **본인만 읽을 수 있는 테이블**에 둔다 (RLS: `auth.uid() = user_id`).
- 같은 행에 필드별 공개 여부 맵 `visibility jsonb`를 저장한다.
- 타인 조회는 `get_public_profile(handle)` — `SECURITY DEFINER` RPC가 `visibility`를 보고 공개 필드만 골라 반환한다. 테이블 자체는 anon에 노출하지 않는다.

### 3D 모델을 통한 누설

몸무게·골격근량으로 체형 morph를 만들면, 수치를 가려도 실루엣으로 드러난다.

- 신체 스탯이 비공개면 **타인 뷰에서는 표준 체형 마네킹**을 보여준다.
- morph 값은 클라이언트가 아니라 RPC 응답 단계에서 이미 제거되어 있어야 한다 (공개 응답에 비공개 morph 파라미터가 섞이지 않도록).

## 3. 라우팅과 인증

| 경로 | 내용 |
|---|---|
| `/` | Press Start 랜딩 + Google 로그인 |
| `/me` | 내 캐릭터 시트, 인라인 편집 |
| `/p?u=<handle>` | 공개 뷰 |
| `/settings` | 공개 범위 일괄 관리 |

- 정적 export(`output: 'export'`)에서는 `/p/[handle]` 같은 동적 경로를 빌드 시점에 만들 수 없다. 공개 프로필은 `/p?u=handle` 형태로 **클라이언트에서 fetch**한다.
- Google 로그인은 PKCE 콜백 페이지를 클라이언트에서 처리한다.

## 4. 레이아웃

### 데스크톱

클래식 MMORPG 캐릭터 정보창 구도.

- 중앙: 3D 캐릭터
- 좌우: 장비 슬롯 4개가 몸의 해당 부위 높이에 맞춰 배치 (투구는 머리 옆, 신발은 발 옆)
- 오른쪽: 스탯 시트 패널
- 슬롯 hover → 3D 모델의 해당 부위가 빛나고, 슬롯과 부위 사이에 가는 연결선이 그려진다

### 모바일

- 상단 55vh: 3D 캐릭터
- 하단 바텀시트: 탭 (스탯 / 장비 / 클래스·자산)
- 바텀시트를 끌어올리면 캐릭터가 줄어들면서 위로 밀려난다

## 5. 디자인 시스템: Quiet HUD

> **평소엔 고요하고, 데이터가 바뀌는 순간에만 폭발한다.**

UI의 99%는 흑백 선과 숫자뿐이다. 색과 빛은 이벤트와 레어리티에만 쓴다. 그래야 화려한 이펙트가 싸 보이지 않는다.

### 컬러 토큰 (다크 퍼스트)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#0A0B0E` | 배경, 3D 캔버스 뒤 |
| `--surface` | `#12141A` | 패널 |
| `--line` | `rgba(255,255,255,0.08)` | 1px 프레임, 구분선 |
| `--text` | `#E8EAF0` | 값 |
| `--text-dim` | `#7A7F8C` | 라벨 |
| `--accent` | `#5CF2FF` (마나 시안) | 유일한 UI 강조색, 포커스, 글로우 |
| `--rarity-common` | `#9AA0A6` (회) | 티어, 장비 테두리 전용 |
| `--rarity-uncommon` | `#4ADE80` (녹) | 〃 |
| `--rarity-rare` | `#60A5FA` (청) | 〃 |
| `--rarity-epic` | `#C084FC` (보) | 〃 |
| `--rarity-legendary` | `#FB923C` (주) | 〃 |

### 타이포그래피

- 본문·라벨: Pretendard
- 모든 숫자: Geist Mono 또는 JetBrains Mono, `font-variant-numeric: tabular-nums` (숫자가 굴러갈 때 폭이 흔들리지 않도록)
- 라벨: 11–12px, 대문자, `letter-spacing: 0.12em`
- 값: 크게. 시각적 위계를 숫자에 몰아준다

### 형태

- 4pt 그리드
- radius 두 단계: `2px`, `6px`
- 시그니처 모티프: 패널 모서리의 **코너 브래킷**(ㄱ 모양 꺾쇠 4개), `clip-path`로 깎은 모서리
- 그림자 없음. 1px 라인과 글로우만 사용

### 모션 토큰

| 토큰 | 시간 | ease (anime.js v4) | 용도 |
|---|---|---|---|
| `instant` | 120ms | `outQuad` | hover, 토글 |
| `quick` | 240ms | `outExpo` | 패널 진입, 탭 전환 |
| `base` | 480ms | `outExpo` | 숫자 롤링, 바 채움 |
| `epic` | 1200–1800ms | `outElastic(1, .6)` + 타임라인 | 레벨업, 티어업, 장착 |

## 6. 컴포넌트

### CharacterViewport

R3F 캔버스.

- 회전: 수평 360°만 허용. 줌: 좁은 범위로 제한
- idle: 숨쉬기 애니메이션
- 재질: 무광 클레이 또는 Fresnel 림라이트 홀로그램
- 화면 밖이거나 탭이 비활성이면 `frameloop="demand"`로 GPU를 쉬게 한다

### HudPanel

모든 카드의 기본 프레임. 코너 브래킷 + 1px 라인 + 상단 라벨.
진입 시 브래킷이 바깥에서 안으로 모이고 내용이 stagger로 나타난다.

### StatRow

라벨 · mono 숫자 · 단위 · 얇은 게이지 바.

- 값이 바뀌면 숫자가 굴러가고, 옆에 `+0.4kg` 같은 델타가 떠올랐다가 사라진다
- **증감 색은 좋음/나쁨으로 판정하지 않고 중립(`--accent`)으로 둔다.** 몸무게 증가가 누군가에겐 목표일 수 있다

### EquipSlot

정사각형 칸.

- 빈 슬롯: 점선 + 흐린 실루엣 아이콘
- 채운 슬롯: 레어리티 테두리
- hover → 3D 부위 하이라이트. 클릭 → 사이즈 편집 팝오버

### TierBadge / ClassEmblem

SVG 엠블럼. **레어리티 색은 이 두 컴포넌트와 EquipSlot 테두리에만 허용한다.**

### VisibilityToggle

모든 필드 옆에 붙는 자물쇠. 이 서비스에서 가장 중요한 컴포넌트.

- 비공개 전환 시 값이 글리치 문자로 스크램블되면서 블러 처리 — "봉인되는" 느낌
- **"타인에게 보이는 화면 미리보기" 버튼을 반드시 함께 둔다**

### StatInput

숫자 스테퍼 + 단위. 드래그로 값을 조절하는 scrub 입력을 지원한다.

## 7. 이펙트

### 규칙

1. 이펙트는 데이터 이벤트(저장, 장착, 티어 변화)에만 쓴다. 장식용 상시 애니메이션은 3D idle 하나뿐이다.
2. epic 이펙트는 동시에 하나만 실행한다.
3. DOM·SVG는 anime.js, 3D는 `useFrame`과 셰이더로 처리한다. 둘은 공용 이벤트 스토어(zustand)에서 같은 이벤트를 구독해 동기화한다.
4. `transform`과 `opacity`만 애니메이트한다.
5. `prefers-reduced-motion`이면 모든 이펙트를 fade로 대체한다.
6. 이펙트가 정보를 가리면 안 된다. 1.8초 안에 끝나고, 클릭하면 즉시 스킵된다.

### 카탈로그

| 이벤트 | DOM (anime.js) | 3D |
|---|---|---|
| 로그인 부트 | SVG 프레임 라인 드로잉(`svg.createDrawable`), 라벨 stagger | 와이어프레임 → 솔리드 스캔 |
| 스탯 저장 | 숫자 롤링, 델타 플로팅 | 발밑 링 파티클 한 번 |
| 장비 장착 | 슬롯 아이콘이 부위로 날아가는 곡선 경로 | 해당 부위 림라이트 플래시 |
| 티어/클래스 변경 | 화면 가장자리 레어리티 색 스윕, 엠블럼 회전 | 빛기둥 + 카메라 살짝 줌인 |
| 비공개 전환 | 글리치 스크램블 후 블러 | (타인 뷰) 표준 체형으로 morph |

### 예시: 숫자 롤링

```ts
import { animate } from 'animejs';

export function rollNumber(el: HTMLElement, from: number, to: number, digits = 1) {
  const obj = { v: from };
  animate(obj, {
    v: to,
    duration: 480,
    ease: 'outExpo',
    onUpdate: () => { el.textContent = obj.v.toFixed(digits); },
  });
}
```

## 8. 3D 에셋 파이프라인

1. MakeHuman 등 CC0 계열 베이스 메쉬를 Blender로 가져온다.
2. 체중, 근육량, 허리 shape key(morph target)를 만든다. 키는 스켈레톤 스케일로 처리한다.
3. 장비 4종(투구·상의·하의·신발)을 별도 메쉬로 분리하고 `.glb`로 export한다.
4. `gltf-transform`으로 Draco 압축한다.

- 애니메이션: Mixamo idle 모션을 리타겟한다.
- 체형 morph 입력: 키·몸무게·골격근량을 0–1로 정규화해 넣는다.
