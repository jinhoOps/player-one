# Player One — 브랜드 가이드: Cozy Quest

> **평소엔 포근하고, 성장하는 순간엔 반짝인다.**

인생을 RPG처럼 기록하는 서비스지만, 경쟁하는 RPG가 아니라 **내 캐릭터를 아끼며 키우는 생활 게임**의 감성을 따른다.
화면의 주인공은 언제나 캐릭터다. UI는 그 캐릭터가 놓인 따뜻한 종이 위의 정리된 카드들이다.

이전 방향(어두운 SF HUD, 시안 홀로그램, 글리치)은 귀여운 토이 캐릭터와 충돌해서 폐기했다.

---

## 1. 이름과 말투

| 항목 | 내용 |
|---|---|
| 이름 | **Player One** (영문 표기 그대로) |
| 슬로건 | 인생이라는 게임, 주인공은 나. |
| 한 줄 소개 | 내 몸과 일, 자산을 캐릭터 스탯처럼 기록하고 키워요. 무엇을 보여줄지는 항상 내가 정해요. |
| 말투 | 다정한 해요체, 짧은 문장. 게임 용어(스탯·장비·티어)는 쓰되 경쟁·서열 표현은 쓰지 않는다 |
| 피할 말 | "랭킹", "패배", "약함", 수치에 대한 좋고 나쁨 평가 |

- 버튼은 행동을 말한다: "모험 시작하기", "장착", "해제", "저장"
- 숫자 변화는 판정하지 않는다. 몸무게가 늘어난 게 누군가에겐 목표다.

## 2. 로고

- 리프 그린 둥근 사각형 안의 선 옐로 별 + "Player One" 워드마크(Jua)
- 컴포넌트: `src/components/Logo.tsx`, 파비콘: `src/app/icon.svg`
- 별은 항상 정방향. 배지와 워드마크 사이 간격은 배지 높이의 30%

## 3. 컬러

미니멀한 흰 바탕과 무채색 UI 위에, 행동색 하나와 반짝임 하나. 따뜻한 내추럴 톤은 캐릭터 무대에만 쓴다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#FFFFFF` 흰색 | 페이지 바탕 |
| `--bg-deep` | `#F2F2F0` | 게이지 트랙, 탭 바 |
| `--surface` | `#FFFFFF` | 카드 |
| `--surface-soft` | `#F7F7F6` | 타일, 입력칸, 빈 슬롯 |
| `--line` / `--line-strong` | `#EBEBE9` / `#DADAD7` | 테두리, 눌리는 아랫선 |
| `--stage-*` | light `#FFFDF8` · mid `#FFF9F0` · deep `#F3EADB` · line `#ECDFCC` · edge `#DCCAB0` | **캐릭터 무대 전용**: 크림 디오라마 그라데이션과 테두리 |
| `--text` | `#3B2F2A` 코코아 | 본문, 값 |
| `--text-dim` | `#74665B` | 라벨, 보조 문구 (흰 바탕 대비 4.5:1 이상) |
| `--leaf` | `#2A7F50` | **유일한 행동색**: 주 버튼, 포커스, 게이지, 공개 상태 |
| `--sun` | `#F5B83D` | 반짝임: 축하, 파티클, 장착 하이라이트 |
| `--sky` | `#4F9BD9` | 중립 표시: hover한 부위, 슬롯 연결선, 수치 델타 |
| `--danger` | `#C4452F` (+ edge `#93301F` · soft `#FDF3F1` · line `#F2CFC8`) | **되돌릴 수 없는 행동 전용**: 설정의 위험 구역(회원 탈퇴). 수치 판정이나 오류 강조에는 쓰지 않는다 |
| `--rarity-*` | common `#A39A90` · uncommon `#4FAE6E` · rare `#4F9BE0` · epic `#A77BE0` · legendary `#F0A030` | 티어 배지, 장비 슬롯 테두리에만 |

- 다크 모드는 아직 없다(라이트 퍼스트).
- 캐릭터는 자체 파스텔 팔레트를 가진다(피부·머리·옷, `CharacterViewport`의 `PALETTE`). UI 색과 섞지 않는다.

## 4. 타이포그래피

| 역할 | 서체 |
|---|---|
| 디스플레이: 워드마크, 카드 제목, 이름, 큰 숫자 | **Jua** (둥근 한글 디스플레이, `next/font`) |
| 본문, 라벨, 입력 | **Pretendard** |
| 숫자 | Pretendard `tnum`(`.num`) — 굴러가는 숫자의 폭이 흔들리지 않게 |

- 라벨은 12px 굵게, 대문자 변환·자간 없음
- 큰 값은 Jua 24px. 위계는 숫자에 몰아준다

## 5. 형태

- 4pt 그리드
- 반경: `10px`(입력) · `16px` · `24px`(카드·스테이지) · pill(버튼·태그·탭)
- **눌리는 느낌**: 카드와 버튼은 부드러운 그림자 + 아래쪽 단단한 2–3px 선(`--lift`). 버튼을 누르면 2px 내려간다
- 테두리는 1.5px. 목록 구분선은 점선
- 아이콘: 24px 그리드, 1.25px 선, 둥근 접합

## 6. 모션

토이를 탁자에 내려놓듯, **살짝 지나쳤다가 자리 잡는다.**

| 토큰 | 시간 | ease (anime.js v4) | 용도 |
|---|---|---|---|
| `instant` | 120ms | `outQuad` | hover, 토글 |
| `quick` | 240ms | `outQuart` | 내용 등장 |
| `base` | 480ms | `outQuart` | 숫자 롤링 |
| `pop` | 520ms | `outBack(1.6)` | 카드·캐릭터 등장, 슬롯 hover |
| `epic` | 1400ms | `outElastic(1, .55)` | 티어·클래스 변경 엠블럼 |

- 상시 애니메이션은 캐릭터 idle(숨쉬기, 좌우로 살짝 흔들림, 깜빡임)뿐이다.
- `prefers-reduced-motion`이면 모든 움직임을 페이드로 대체한다.

## 7. 이펙트

규칙: 데이터 이벤트에만 쓴다 · epic은 동시에 하나 · 1.8초 안에 끝 · 클릭하면 즉시 스킵 · 정보를 가리지 않는다 · `transform`/`opacity`만.

| 이벤트 | DOM (anime.js) | 3D |
|---|---|---|
| 로그인 부트 | 카드가 열 순서대로 통통 튀어 오른다 | 캐릭터가 바닥에서 튀어 올라 자리 잡는다 |
| 스탯 저장 | 숫자 롤링 + 하늘색 델타가 떠오름 | 발밑에서 선 옐로 반짝이 고리 |
| 장비 장착 | 슬롯 타일이 곡선을 그리며 몸으로 날아감 | 해당 부위가 하얗게 반짝, 옷에 색이 입혀짐 |
| 티어/클래스 변경 | 레어리티 색 은은한 빛 + 캐릭터에서 콘페티 | 레어리티 색 빛기둥 + 카메라 살짝 줌인, 엠블럼 회전 |
| 비공개 전환 | 값이 꾹 눌렸다가(squish) 서리 유리처럼 흐려짐 | (타인 뷰) 평균 체형 |

## 8. 캐릭터 아트

- 머리가 몸만큼 큰 치비 토이. 큰 둥근 머리와 귀, 짧은 몸통과 다리, 내려 둔 짧은 팔
- 얼굴은 단순하게: 잉크색 둥근 눈 두 개 + 짧은 미소. 코·귀·볼터치·디테일한 눈은 넣지 않는다
- 무광 비닐 재질, 조명은 보는 사람 쪽. 장착한 부위는 색 옷, 빈 부위는 기본 무지 옷
- 레퍼런스는 원리만 가져온다. 특정 게임 캐릭터의 디자인을 옮기지 않는다
